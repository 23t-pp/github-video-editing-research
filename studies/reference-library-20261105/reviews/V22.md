# V22 ·《原来遗忘才是真正的死亡》

这条最值得学的是 **来镜先交角色，后交背景**。常见画中画只是放一块副画面；这条把小窗当作下一镜的入口。观众先认出来的是人物，窗再打开，最后才看到新地点。另一个变体是让旧镜缩回小窗，露出新底图。两者都能换景，又不打断视线。

来源：[抖音作品原页](https://www.douyin.com/video/7558686913511558439)，自由思想家，页面显示 2025-10-08 11:25。分析对象是网页公开播放流：1920×1440（4:3）、60 fps、BT.709，画面 18.950 秒，音轨 18.970 秒。保留 F0–F1136 的实际 PTS；60 fps 是这份视频流的规格，不能反推作者工程帧率或补帧方式。

## 音乐和卡点

本地信号分析在混音和分离候选中均找到 **约 115.2 BPM** 的节奏候选，一个拍周期约 0.521 秒，半拍约 0.260 秒。独立频带分析也找到对应周期；另有 57.6 / 230 的倍半速解释和约 153.8 的能量基线结果。**不把候选当作唯一曲速或确认的曲名。** 对白、打击音和转场音也会形成起音。

## 用你的素材怎么练

| 难度 | 技法与素材条件 |
|---|---|
| **2/5** | 同琴或同道具的景别接力、相似构图叠化、照片尾字渐显。适合道具清楚、拍摄方向相近的素材。 |
| **3/5** | 方窗扩屏、三条补景、斜卡与四格接力。适合来镜有清楚的脸、门或轮廓，能预留窗口位置。 |
| **4/5** | 人物提前入场、轮廓白闪、前景清晰而后景连续换。适合主体与背景边缘分明、动作连续的素材。难在发丝、手指、肩线和琴盒逐帧跟踪。 |

从 **F108 → F118 → F138** 开始：把三点写成相对时间 **0 / 167 / 500 ms**。在 OpenChatCut 或剪映建四层：A 底图、B 来镜窗、B 人物抠像、音乐。先锁人物位置，再开窗，最后把完整 B 接上；两条 B 画面共用同一源帧，人物接管时才不会跳。HyperFrames 可细调窗口形状、轮廓白层和扩张曲线。若仍用你的 **16:9 / 24 fps** 工程，先试相对 **0 / 4 / 12 帧**，把额外的横向空间用作留白，再按目标音乐的实际起音重定时间。练熟以后再做 F429 的动态抠像换底。

## 操作证据

1. `ffprobe` 读取帧率、流时长与色彩；SHA-256 与 V01–V21 核对无重复。取到的是公开播放流，原始媒体保存在本地配置指向的位置。
2. `analyze-native-frames.mjs` 按播放流原帧解码，保留 1,137 条 PTS 与逐帧指标；`extract-native-jpg.py` 输出 1,137 张 1920×1440 JPG 及对照表。图谱每页最多 60 张，没有帧率转换。画面复核查看了全片总览和抽样图，并对重点接缝查看前后帧；这不是全片原尺寸人工逐张审片。
3. `extract-mixed.mjs` 与 `hash-integrity.mjs` 提取并核验 AAC。HyperFrames 本地信号分析与 montage 能量基线交叉参考；本地模型另存分离候选。全程未上传音视频到分析服务。
4. 用本地《寻梦环游记》原片的缩略图索引定位候选，再看原尺寸对应画面，核对花瓣、亮闪、祝福手与全家福。 [原片时间码 CSV](../evidence/V22/verified/source-pairs.csv)
