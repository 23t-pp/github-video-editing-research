# V21 逐帧画面拆解｜彼得与格温

这支 30.933 秒混剪用一个尚未完成的动作串起回忆：蜘蛛侠伸手、丝尖张开，画面两次用记忆延缓结果，最后才回到格温坠地与悬起。第一次，彼得回望，格温的回忆占据他视线左侧；第二次，蜘蛛丝本身变成贯穿多张人脸的线。结尾仍保留一边回忆、一边运动中的丝，随后给一个原生近黑帧切回低机位。可迁移的核心是**保留一条能读出方向的当前动作，再让回忆打断或占领它**。

画面证据来自用户提供的 `一帧一帧闪回的_是我无法割舍的_超凡蜘蛛侠_格温_了不起的混剪团_whateverhappens_蜘.mp4`。源文件 SHA-256 `e8f5c4c5c2955cc444aa092f32a601051b009de774e7341d64026096591efda6`。视频 H.264、1620×1080、3:2、30/1 fps、8-bit `yuv420p`、有限范围 `bt709` 矩阵，未见 HDR 传递标记；色彩描述按当前解码后的画面，不反推母片原始调色。音频流及容器 30.975986 秒，视频流 30.933333 秒，最后一个画面的 PTS 为 30.900000 秒。

`N` 是原生帧号，`G` 是每秒 60 格时间轴，均从 0 起。`N n` 对应 `G 2n` 和 `G 2n+1`，间隔为 1/60 秒；没有补出新画面。范围均为 `[起点, 终点)`。表中秒数是显示近似，精确定位按帧号。机器解码全量 928 原帧、验证 PTS 每帧递增 512 ticks（时间基 `1/15360`）；人工浏览 16 页原帧图谱全部 928 格，另复查 47 张原尺寸 JPEG。视觉工作未独立试听，也未渲染复刻样片。

人物关系依赖位置、距离和动作，不只靠闪得快。花束镜的两人面向中间，校园正反打让各自眼线接上，夜景里彼得看向左侧的空形和回忆，走道又改成一人在近处、一人在远处。末段取连续丝作为「够得到吗」的动作线，左脸离它越来越远。文本也用两种尺度：开头大字贴在镜片或中景并参与遮挡，底中小字通常只补信息、跟人物脸和手错开。色彩以暗青蓝、黑位和局部红色为底，明亮花束段引入粉紫，脸部回忆用暖肤和发丝高光把眼睛引回来。手机自拍虽然是快乐记忆却偏蓝，不能把所有记忆机械地做成暖色。

从成片能确认是合成设计的部分：不透明白板边界、人物挡字、五条直线与圆环及多脸叠层、RGB 通道分离和画面条带错位、独立墓地栏、轮廓内部的星尘。底片可能已有的部分：演员视线和手势、镜片中的人物反影、手机屏内照片、悬吊动作与会分叉的蜘蛛丝。没有同帧电影源对照时，把这些记录为影片画面元素或可能已有的 VFX，无法断言现场实拍、替身、CG 比例或混剪作者另做的程度。精确 LUT、插件、字体、原工程、时间重映射与 alpha 都不能从这条成片唯一确定。上述配方是等效实现建议，尚未执行复刻渲染。
