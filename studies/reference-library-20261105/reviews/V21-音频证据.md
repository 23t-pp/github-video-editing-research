# V21 音频与声画对位

原音轨从 0 开始，为 HE-AACv2、44.1 kHz、双声道。原片解码得到 1,366,041 个立体声采样位置，有效时长 **30.975986395 秒**，比 928 个原生 30fps 画面的结束边界长约 **42.653 毫秒**。音频事件的毫秒时间以原片 0 点为基准，0 基 60Hz 帧号用 `floor(t × 60 + 0.5)` 取最近格，量化误差最多半格，约 8.333 毫秒。原生画面 N 对应偶数格 G=2N。音频网格有 G0000–G1858，末端最近边界是 G1859，比音频有效结束晚 7.347 毫秒。G1856–G1858 已超出原生画面区间。

## 轨道和验证

| 轨道 | 实际处理 | 验证与边界 |
|---|---|---|
| `V21__mixed.m4a` | 直接复制原始 AAC 编码包，保留混音 | 源和提取物 671 个 AAC 包内容哈希序列完全一致。解码 PCM 的共享前缀逐样本一致，容器尾部多解出 24.059 毫秒，分析截到原片有效时长。源混音 -6.40 LUFS、+3.84 dBTP，未做归一化。 |
| `V21__music-candidate.m4a` | 本地 `UVR_MDXNET_KARA_2.onnx` 生成 Instrumental，AAC-LC 192 kbps 目标码率 | CPU 2 线程推理 30.484 秒。分离 WAV 与原片等长，M4A 全部解码通过，对 WAV 的开头互相关最优延迟为 0 样本，AAC 末端多 22.653 毫秒。候选 -13.84 LUFS、+0.18 dBTP。 |
| `V21.source.wav` | 原片 AAC 直接解码为 44.1 kHz 双声道 float32 | 供本地重跑的中间文件，长度与源音轨有效采样数完全一致。 |

音频分析未进行人工试听。曲名、对白/人声/音效来源、候选分离残留及音乐损伤均未确认。分离模型、参数与哈希见 `V21-candidate.json`。原混音和候选用各自的轨道编号区分，声画实测起音来自原混音。

## 周期与结构候选

- 同库 HyperFrames 0.8.216 signal provider 实际输出 **97 BPM**、周期置信值 0.194 和 103 个谱起音。montage 基线为 96.8 BPM。HF 的 4 拍重音推断为低置信度。
- 独立 4.989 毫秒步长的谱通量测量，在 1–10、10–20、20–30 秒均测到约 618.6 毫秒周期。全片原混音自相关在该周期为 0.179，分离候选为 0.436；双周期约 1.237 秒更强，候选为 0.550。约 97 BPM 可作为复刻用脉冲网格，约 48.5 和 194 BPM 对应周期的半速和倍速解释。
- 按分离候选 39 个接近 97 BPM 网格的起音做加权拟合，得到 **618.557 毫秒周期、32.805 毫秒相位**，入选锚点的拟合绝对残差中位数 **2.462 毫秒**。拟合过程仅用音频。CSV 同时列每格最邻近实测起音，以区分实际起音、拟合网格和缺少近邻的网格。
- HF 的音色/chroma分段候选为 0–8.125 秒、8.125–12.425 秒、12.425–22.315 秒、22.315–30.976 秒，三个内部边界吸附到推断拍点，中位移动 125 毫秒。独立 400 毫秒前后频带比较发现 4.365 / 8.650 / 11.140 / 18.563 / 23.512 / 28.051 秒附近的能量上升，以及 15.709 / 25.507 秒附近的回落。11.14 和 18.56 秒附近也在分离候选中检出音色变化。这些是信号结构边界候选，副歌、乐句和鼓点类别待听辨。

全片 25 个 `scdet` 强变化候选中，±16.667 毫秒匹配 6 个，±33.333 毫秒匹配 10 个。将全部起音以 1000 个不同偏移循环平移后，两档基线计数中位数为 4 / 9，95% 分位为 8 / 13。选段有清楚的局部接近，整体数据支持逐个复核，画面候选包含光闪、运动和真实切换。判定卡点需要同时确认视觉阶段和声音来源。

## 文件索引

- `V21.json` 用于参考库学习页，保留 HF 和 250ms RMS 结构，另附毫秒与帧号。
- `V21-analysis.json` 保存独立频带分析、结构候选、相位拟合、平移基线及候选验证。
- `V21-onsets.csv` 和 `V21-candidate-onsets.csv` 分别记录混音 169 个 4.989ms 步长谱通量起音与分离轨起音。混音中 43 个起音按峰值上四分位标为强。
- `V21-audio-60hz.csv` 为每个 60Hz 浏览格上的 RMS 与通量插值采样，`V21-pulse-grid.csv` 为独立拟合周期。两份文件的 60Hz 量化均以真实音频坐标为基准。
- `V21-sync-reviewed.csv` / `.json` 为上表完整证据，`V21-sync-candidates.csv` 保存自动候选全量。
