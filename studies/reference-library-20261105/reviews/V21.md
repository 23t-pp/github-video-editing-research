# V21 · 超凡蜘蛛侠与格温

这条混剪反复让观众等同一个动作的结果。蜘蛛侠伸手，蛛丝向格温延伸，画面把相处时的记忆塞进这段等待。用来串场的是五条线和圆点、钟面、同方向的蛛丝。记忆可以换，观众仍然知道现在发生到了哪里。

视频流 **30.933333 秒**，1620×1080，源 30fps 共 **928 个原帧**。本次按要求以 **60Hz** 拆解，得到 **1,856 个全尺寸 JPG 路径、31 页采样图谱**。`S` 为采样号，`N` 为原帧号，均从 0 开始。每张原帧出现在 `S=2N` 和 `S=2N+1` 两个位置，第二张用硬链接保存。图谱的 `=` 标出沿用同一原帧的位置。证据报告里的 `G` 与 `S` 是同一套 60Hz 编号。 [逐样本映射](../data/frame-analysis/V21-60hz.csv)

机器解码并计算了全部原帧指标。画面复核覆盖 16 页原帧缩略图和 47 张原尺寸关键帧。学习页把全片分成 20 段，边界按起点含、终点不含记。 [20 段结构化报告](V21.json) · [逐段画面证据](V21-画面证据.md)

## 声画对位

原混音流复制的 671 个 AAC 包与片源一致。原音轨有效时长 30.975986 秒，超过视频结束边界约 42.653 毫秒。用于声音定位的最后 3 个 60Hz 格只有音频。 [原混音 M4A（在下载包内）](https://github.com/23t-pp/github-video-editing-research/releases/download/reference-library-v01-v25-2026-11-10/reference-library-v01-v25.zip) · [音乐主体候选 M4A（在下载包内）](https://github.com/23t-pp/github-video-editing-research/releases/download/reference-library-v01-v25-2026-11-10/reference-library-v01-v25.zip)

HyperFrames 信号分析测得 **约 97 BPM**，`montage` 基线为 96.8 BPM。独立频带分析也找到约 0.619 秒周期，分离候选仍支持这个周期。约 48.5 与 194 BPM 是倍半速解释。曲名、下拍和分离残留待试听确认。 [音频证据与方法](V21-音频证据.md)

练习时优先对齐局部的视觉变化。11.167 秒的近全白峰比最近混音谱峰早约 2.95 毫秒。18.578 秒附近的起音落在旧画面亮闪与新底图出现之间。三栏白板相邻启动相隔 600 和 666.7 毫秒，接近一个脉冲周期，第三栏仍比最近混音谱峰晚约 43.8 毫秒。全片自动候选的对齐数量也落在平移基线范围内。适合按实际片段标记逐处调整。 [11 个人工复核的声画事件](../data/sync-analysis/V21-sync-reviewed.csv) · [脉冲候选网格](../data/audio/V21-pulse-grid.csv)

## 技法练习与难度

| 技法 | 难度 | 练习顺序与验收 |
|---|---:|---|
| 三竖窗接力 | 2/5 原型，3/5 贴近参考 | 用旧照片和三条墓地素材。三栏起点相对第一栏可先摆为 0、36、76 个 60Hz 样本。窗宽、白层透明度、遮盖顺序分别验收，再按素材修边。对应 T05。 |
| 钟面闪回 | 2/5 | 同一底景上用三个短动作片段试透明度。前两次退回钟面，第三次停在动作。对应 T02。 |
| 记忆线轨与圆点 | 3/5 原型，4/5 动态遮挡 | 五条线可先摆在画高约 27%、40%、53%、66%、78%。用 SVG 路径和点位驱动软边记忆窗，等视线清楚后再让头肩盖住线。对应 T17。 |
| 眼罩字与半调背景字 | 4/5 | 先让字的弧度和透视跟上镜片，再做黑框裁切。花束镜将粉紫半调字放在底片和人物前景之间，验收发丝、花梗、花瓣缝。对应 T10。 |
| 格温和伞的保形星尘 | 4/5 | 动态遮罩内叠粒子材质，逐渐压下人物本身纹理，保留轮廓和画外底图。验收人物移动时的边缘。对应 T09。 |

**建议从三竖窗开始。** 用 OpenChatCut 摆主镜头、分轨和音轨。用 HyperFrames 做三栏裁切、曲线路径、贴景字和人物遮罩。切点、位置及层级是可学的配方，作者实际使用的字体、插件、动态遮罩和速度曲线需要原工程确认。本次完成拆解及入库，复练结果以另行渲染的样片验收为准。

## 实际操作记录

1. `ffprobe` 读取时长、流信息和源帧率。SHA-256 用于确认 V21 与已有参考的文件身份。
2. `node ./scripts/analyze-native-frames.mjs <V21本地清单> V21` 解码原帧、保留真实 PTS，计算亮度与变化候选，生成 16 页原帧图谱。
3. `python -X utf8 ./scripts/sample-v21-60hz.py <V21原视频>` 将每张原帧写成 1620×1080 JPEG，再为第二个采样位置建硬链接。脚本生成 CSV 和标注采样号、原帧号的图谱。
4. `node ./scripts/build-study.mjs` 把 V21 的 20 段、图谱、原混音和音乐主体候选接入学习页。`node ./scripts/audio/validate-library.mjs` 检查两轨的 SHA、字节数与完整解码。 [学习库启动说明](../README.md)
