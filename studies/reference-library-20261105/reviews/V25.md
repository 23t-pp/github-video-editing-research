# V25 ·《灵笼》人类能战胜玛娜生态吗

这条混剪最值得练的是**让观众提前看见下一镜的一部分**。先用白色形状引导眼睛，下一帧在同一位置放进新画面，最后让新画面接管。作者在同一条片里用了横窗、竖条、三角形和人物轮廓。即使镜头换得很快，观众也能沿着同一个脸、同一只手或同一束光看下去。

源视频为 **1920×1080、16:9、原生 30 fps、21.233333 秒**。全片保存 **637 张原尺寸 JPG、11 页连续图谱**。帧号从 F0 开始，F636 的显示时间戳是 21.200 秒。一帧约 33.33 毫秒。 [全片总览](../evidence/V25/overview.jpg) · [逐秒图谱](../evidence/V25/timeline-01.jpg) · [帧号、时间与 JPG 路径](../data/frame-analysis/V25-jpg-map.csv)

## 文字与视觉层次

- 对白字幕是**底部居中的白色粗字，带深色软边**。例如「为了完成你的计划」跨过分窗和枪火，「那些实验室里的克隆体和我」在三角窗和漫画放射线里保持相近位置。F455 的白竖条经过字幕后面时，字幕仍能读到。复做时把对白字独立成轨，置于合成之上。
- 小号双行「摘星.K / ZhaiXing.K」与对白字幕分开。早段贴近底边，中后段多见于上方中央。末镜「同于涅槃」F589 已可读，F609–615 逐渐发光、碎化，F616 确认消失。署名可用小号宽字距，正文用更粗、更大的白字。成片里可看到排版，字体与具体阴影参数未核实。
- 快的段落靠**一个主要焦点加若干小变化**。冷蓝底配红点时，红点负责引导眼睛。红色面部占满时，用白甲剪影把下一镜的重心提出来。F393 的长一点的挥剑和 F586 起的尾镜给快切留出了呼吸。 [字幕和署名细节](../evidence/V25/verified/09_字幕与署名.jpg)

F326–331 的红眼轮廓从下方抬起，挡住橙发脸，F332 才换成同类兽形的冷色低机位。另一个可逐帧练的接法是 F344 起横向伸出的手臂与 F369 横刀特写。两镜让横线占据相近高度，动作读得顺。F438 的大武器还盖过剑士镜头的上黑边，提供了明确的叠放证据。 [八组精选帧](../evidence/V25/verified/README.md)

## 音乐卡点怎么读

本地分析从混音中测到约 **0.132 秒**的短周期。HyperFrames 的拍点候选为 **152.1 BPM**，把三小格合在一起约为 0.395 秒，与主周期峰接近。30 fps 下四帧是 **0.133 秒**。因此可以先拿 F72–F92 的每四帧换窗练音乐细分，实际剪辑时再听每个开窗位置。

| 画面节点 | 最近谱峰与画面的差值 |
| --- | ---: |
| F72 / 76 / 80 三次竖窗 | −5.44 / −29.03 / +17.23 ms |
| F84 / 88 / 92 三次横窗 | −6.35 / −19.95 / −8.62 ms |
| F317 闪白 / F318 换底 | 同一低频峰，对应 +14.29 / −19.05 ms |
| F438 武器先入 | +1.81 ms |
| F467 大轮廓先入 / F471 换底 | −2.04 / −0.68 ms |
| F549 红场提亮 | −1.59 ms |

表中差值按「声音时间减画面时间」计算，负值表示声音先到。四帧窗都在一个画面帧之内找到邻近峰，其中 F84 只匹配到低频，其他节点还测到提前约 25–35 毫秒的高频峰。这些峰来自整段混音，可能包含音乐、对白或音效。F17、F21、F180 等视觉节点在约 1.5 帧的窗口内没有测到达到阈值的峰，复做时可以继续按画面的动作或遮挡切。曲名未核实。 [逐节点声画表](../evidence/V25/verified/cue-alignment.csv) · [原混音（在下载包内）](https://github.com/23t-pp/github-video-editing-research/releases/download/reference-library-v01-v25-2026-11-10/reference-library-v01-v25.zip)

**练卡点用原混音，重新配画面可以先试听分离候选。** 分离后仍测到约 0.132 秒的高频细分。原混音与候选长度同为 21.198957 秒，波形对齐未测到整体样本偏移。两条轨响度不同，候选也可能残留对白或音效。 [音乐主体候选（在下载包内）](https://github.com/23t-pp/github-video-editing-research/releases/download/reference-library-v01-v25-2026-11-10/reference-library-v01-v25.zip) · [周期拟合](../evidence/V25/verified/pulse-grid.json)

## 按难度练习

| 难度 | 技法 | 适合的素材 |
| --- | --- | --- |
| **2/5** | 同位置亮点接镜、冷暖选镜、对白分轨 | 有醒目眼睛、刀光、车灯、火焰或其他孤立高光的镜头。 |
| **3/5** | 每四帧揭一块、星形与三角遮罩、漫画冲击 | 脸部居中、主体轮廓清楚，或打斗中有明确撞击点。 |
| **4/5** | 人物或武器先入，再换底，叠加短暂 RGB 彩边 | 来镜的边缘可以追踪，手、肩、武器在切点前后具有连续动作。 |
| **5/5** | 多前景遮挡、拼窗、对白、色彩与节奏一起维持 | 同一组素材同时有中近景和完整动作，能够制作透明层并逐帧检查边缘。 |

**第一练只做 F72–F83 的 12 帧。** 在剪映建 30 fps 时间线，底轨放旧镜，把同一来镜复制到三条上层。各加一个矩形蒙版，位置为中、左、右。相对第 **0、4、8 帧**各放一帧同形白片，相对第 **1、5、9 帧**开始显示各区画面，已出现的区继续保留。先逐帧检查白片和画窗的边界是否重合，再正常速度试听。第二练拿掉白条，把来镜的人或武器做透明前景，提前放到旧镜上，检验 F467–F471 这种前景接力。
