# V24 的逐帧取证和命令

以下命令在本机项目根目录运行。用 PowerShell 将视频路径作为一个参数传递，避免文件名中的下划线和中文影响查找。

```powershell
$r = 'outputs/reference-library-20261105'
$w = 'work/v24-readyplayer'
$src = 'D:/素材/你的V24参考视频.mp4'
$node = (Get-Command node -ErrorAction Stop).Source
$python = (Get-Command python -ErrorAction Stop).Source
$manifest = (Resolve-Path -LiteralPath "$w/manifest.local.json").Path

ffprobe -v error -show_streams -show_format -of json $src
Get-FileHash -LiteralPath $src -Algorithm SHA256
& $node "$r/scripts/analyze-native-frames.mjs" $manifest V24
& $python -X utf8 "$r/scripts/extract-native-jpg.py" V24 $src
```

1. `ffprobe` 查看分辨率、帧率、时间戳精度和音画各自时长。视频为 30 fps、15.300 秒。
2. `Get-FileHash` 用 SHA-256 给文件作标识。相同文件再次提交时可识别，片名相同也能区分实际版本。
3. 帧分析脚本用 FFmpeg 解码，记录每个原帧的实际 PTS 和与前一帧的像素变化。它找到 17 个较强变化候选，包含局部闪入和运动。人工用连续图核对后，另记了 47 个视觉锚点。
4. JPG 脚本用 `-fps_mode passthrough` 输出 F0000–F0458，逐张检查 JPEG 可读。每页放最多 60 张图，八页覆盖 459 张原帧。

```powershell
$env:REF_AUDIO_MANIFEST = $manifest
$env:REF_AUDIO_WORK = (Resolve-Path -LiteralPath "$w/audio").Path
& $node "$r/scripts/audio/analyze-library.mjs" V24
& $node "$r/scripts/audio/extract-mixed.mjs" --seekable --manifest $manifest V24
& $node "$r/scripts/audio/hash-integrity.mjs" V24
```

音频分析脚本找谱峰和周期。提取脚本以 AAC 码流复制生成可寻址 M4A。最后一个命令分别核对编码流和原生双声道 PCM，原混音逐样本一致。另按六频带查 64 个标注节点的起音，并与本地电影音轨做局部对齐。音乐主体采用本地 UVR 模型，曲库使用与复核记录同一份 673,583 样本/声道的候选。

原片比对先把本地电影每四帧缩成一张代理图找候选，再围绕候选解码彩色连续帧。实际核对 25 组，记录本地电影版的真实 PTS。 [原片比对过程](../evidence/V24/verified/原片与合成归属.md)
