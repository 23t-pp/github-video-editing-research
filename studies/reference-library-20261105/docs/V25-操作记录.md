# V25 · 中文操作记录

这里的命令从工作区根目录运行。PowerShell 中的 `$src` 是参考视频的路径。把下方的「你的参考视频.mp4」换成实际文件名，带空格也可以。

```powershell
$src = 'D:/素材/你的V25参考视频.mp4'
$library = 'outputs/reference-library-20261105'
$manifest = 'work/v25-linglong/manifest.local.json'
$runtime = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies'
$node = Join-Path $runtime 'node/bin/node.exe'
$py = Join-Path $runtime 'python/python.exe'
```

## 1. 核对源视频

```powershell
ffprobe -v error -show_streams -show_format -of json "$src"
Get-FileHash -LiteralPath "$src" -Algorithm SHA256
```

`ffprobe` 读文件头与流信息。`-v error` 只显示错误，`-of json` 将结果组织成便于程序读取的数据。比对了帧率、分辨率、色彩、音频与视频各自的时长。文件指纹用于核对两次分析是否来自同一份素材。

本次读到 1920×1080、30/1 fps、BT.709 有限范围、H.264，视频 21.233333 秒，音轨为 44,100 Hz 双声道 HE-AACv2。视频有 637 帧，实际 PTS 增量约 1/30 秒。SHA-256 为 `9f6e43fb63a67d5894b14a730271738e534a398b5a996fac07d21e5790fb01ed`。画面字幕、署名与文件名均作为分析材料读取。

## 2. 导出每一帧

```powershell
& $node "$library/scripts/analyze-native-frames.mjs" $manifest V25
& $py -X utf8 "$library/scripts/extract-native-jpg.py" V25 "$src"
& $py -X utf8 'work/v25-linglong/check-frame-index.py'
```

第一条生成 PTS、相邻帧变化候选和最多 60 帧一页的图谱。第二条使用 FFmpeg 的 `-fps_mode passthrough` 按源帧逐张输出 JPG。第三条逐张检查尺寸、文件可读性和 CSV 对应关系，并将总览标注为实际原帧号。都在 V25 名下落盘。机检找到 52 个较大变化候选，包含镜头变化、画面运动和闪光。 [逐帧映射](../data/frame-analysis/V25-jpg-map.csv) · [实际 PTS](../data/frame-analysis/V25-pts.json) · [机检结果](../data/frame-analysis/V25.json)

看完 11 页连续图谱后，逐组查看白片与来镜窗、人像压底、亮度变化和末句消失。快速复查时，可以先看 F72 与 F73，随后看 F317 与 F318，最后看 F467 与 F471。这三对画面分别说明局部揭幕、白闪换全幅与前景先入。 [八组精选帧](../evidence/V25/verified/README.md)

## 3. 保存音轨并复算卡点

```powershell
$env:REF_AUDIO_MANIFEST = (Resolve-Path $manifest).Path
$env:REF_AUDIO_WORK = (Resolve-Path 'work/v25-linglong/audio-pipeline').Path
& $node "$library/scripts/audio/extract-mixed.mjs" --seekable --manifest $env:REF_AUDIO_MANIFEST V25
& $node "$library/scripts/audio/hash-integrity.mjs" V25
& $node "$library/scripts/audio/analyze-library.mjs" V25
& $py -X utf8 "$library/evidence/V25/verified/align.py" --frames '72 76 80 84 88 92' --output 'work/v25-linglong/four-frame-check.csv'
```

第一条保存可寻址的 M4A 文件，复制原始 AAC 码流。第二条比较源文件与 M4A 的 AAC 码流和解码后的双声道 PCM。两者都一致。第三条生成 HyperFrames 拍点候选与整段谱通量分析。第四条读取已保存的混音起音列表，把六次开窗的帧号换成时间，在左右 1.5 帧范围内分别查找宽频、低频和高频谱峰。时间差按声音减画面计算。 [原混音（在下载包内）](https://github.com/23t-pp/github-video-editing-research/releases/download/reference-library-v01-v25-2026-11-10/reference-library-v01-v25.zip) · [起音列表](../evidence/V25/verified/mix-onsets.csv) · [声画表](../evidence/V25/verified/cue-alignment.csv) · [细分周期拟合](../evidence/V25/verified/pulse-grid.json)

原混音有 934,874 个样本每声道，解码长度 21.198957 秒，距离视频结束约 34.38 毫秒。源轨测得约 −7.37 LUFS 和 +2.87 dBTP。为避免分离输入由浮点转成 24 位 PCM 时削波，仅对用于分离的 WAV 乘以 0.65 增益，再以本机 UVR 模型推理。

```powershell
$env:REF_AUDIO_WORK = (Resolve-Path 'work/v25-linglong/audio/gain-input').Path
& $node "$library/scripts/audio/finalize-library.mjs" V25
& $node "$library/scripts/audio/validate-library.mjs"
& $node "$library/scripts/build-study.mjs"
```

`finalize-library.mjs` 读取已分离的 WAV 或复用通过指纹核对的候选，并更新音乐索引。V25 最终采用可拖动进度的 M4A，解码样本数与原混音一致。`validate-library.mjs` 逐条校验文件指纹、完整解码与音轨时长。`build-study.mjs` 用拆解、音频和帧数据生成学习页。这一轮对声音做了信号分析，试听、具体曲名和分离残留的听感仍待核对。 [音乐主体候选（在下载包内）](https://github.com/23t-pp/github-video-editing-research/releases/download/reference-library-v01-v25-2026-11-10/reference-library-v01-v25.zip) · [分离数值复核](../evidence/V25/verified/audio-audit.json) · [音频校验](../data/audio/validation.json) · [学习库覆盖](../data/coverage.json)
