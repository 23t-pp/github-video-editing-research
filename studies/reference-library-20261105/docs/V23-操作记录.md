# V23 拆解命令与核验

在本机项目根目录运行。清单保存在 `work/reference-v23/manifest.local.json`。

```powershell
$r = 'outputs/reference-library-20261105'
$node = (Get-Command node -ErrorAction Stop).Source
$python = (Get-Command python -ErrorAction Stop).Source
$manifest = (Resolve-Path -LiteralPath 'work/reference-v23/manifest.local.json').Path
$src = (Get-ChildItem -LiteralPath (Join-Path $env:USERPROFILE 'Downloads') -File -Filter '到底怎么样的结局*.mp4').FullName
$env:REF_AUDIO_MANIFEST = $manifest
$env:REF_AUDIO_WORK = (Resolve-Path -LiteralPath 'work/reference-v23/audio-library').Path

ffprobe -v error -show_streams -show_format -of json $src
Get-FileHash -LiteralPath $src -Algorithm SHA256
& $node "$r/scripts/analyze-native-frames.mjs" $manifest V23
& $python -X utf8 "$r/scripts/extract-native-jpg.py" V23 $src
& $python -X utf8 'work/reference-v23/make_evidence.py'
& $node "$r/scripts/audio/analyze-library.mjs" V23
& $node "$r/scripts/audio/extract-mixed.mjs" --seekable --manifest $manifest V23
& $node "$r/scripts/audio/hash-integrity.mjs" V23
```

1. `ffprobe` 读取画面与音轨的边界。视频为 30 fps、747 帧。FFmpeg 用 `-fps_mode passthrough` 逐帧输出。JPG 尺寸 1440×1080，逐张核对能读、编号连续。
2. `analyze-native-frames.mjs` 写出原生 PTS、变化指标和 13 页图谱。变化较强的 59 个位置是机器候选，包含换镜、分块闪亮和恢复正常色的瞬间。另由人眼检查相邻帧，保留这些区别。
3. 声音以源文件为时间基准。默认碎片式 M4A 虽保留 AAC 码流，这次重解码边界出现约 3.4 ms 的长度差。改用可寻址文件输出的普通 M4A 后，AAC 码流和原生双声道 PCM 的哈希都与源轨相同。 `--seekable` 保留了本次命令选择。

本地模型分离读取既有的 `work/reference-v23/audio-library/V23.stereo.wav`，该文件为第一音轨解码得到的 44.1 kHz 双声道 PCM。下面生成分离候选并验收已入库的音频。

```powershell
& 'work/reference-library-20261105/audio-env/Scripts/python.exe' -X utf8 "$r/scripts/audio/separate-local.py" V23
& $node "$r/scripts/audio/finalize-library.mjs" V23
& $python -X utf8 'work/reference-v23/index-reference.py'
& $node "$r/scripts/build-study.mjs"
& $node "$r/scripts/audio/validate-library.mjs"
```
