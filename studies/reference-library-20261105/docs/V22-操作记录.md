# V22 实际操作与复核

在本项目根目录运行。公开播放样本已放在 `work/reference-v22`，本地清单只在本机使用。

```powershell
$r = 'outputs/reference-library-20261105'
$node = (Get-Command node -ErrorAction Stop).Source
$python = (Get-Command python -ErrorAction Stop).Source
$manifest = (Resolve-Path -LiteralPath 'work/reference-v22/manifest.local.json').Path
$src = (Get-ChildItem -LiteralPath 'work/reference-v22' -Filter 'V22*.mp4' -File).FullName
$env:REF_AUDIO_MANIFEST = $manifest
$env:REF_AUDIO_WORK = (Resolve-Path -LiteralPath 'work/reference-v22/audio-library').Path

ffprobe -v error -show_streams -show_format -of json $src
Get-FileHash -LiteralPath $src -Algorithm SHA256
& $node "$r/scripts/analyze-native-frames.mjs" $manifest V22
& $python -X utf8 "$r/scripts/extract-native-jpg.py" V22 $src
& $node "$r/scripts/audio/extract-mixed.mjs" --manifest $manifest V22
& $node "$r/scripts/audio/hash-integrity.mjs" V22
& $node "$r/scripts/audio/analyze-library.mjs" V22
```

1. `ffprobe` 查看尺寸、编码、时长、帧率和色彩。SHA-256 核验文件身份，不能证明两条混剪用了不同的歌。
2. 原帧分析输出 PTS 和图谱。JPG 脚本用 `-fps_mode passthrough` 保留解码帧，将 JPEG 通过管道交给 Python 写盘并逐张核验。
3. 混音脚本用 `-map 0:a:0 -vn -c:a copy` 选中第一条音轨、去掉画面并复制 AAC。完整性脚本核验复制前后的 AAC 与解码音频。
4. 声音分析计算谱通量、候选拍点和响度。分离单独使用本机已有的 ONNX 模型。

分离步骤读取 `$env:REF_AUDIO_WORK/V22.stereo.wav`，这是第一条音轨解码成的 44.1 kHz 双声道 PCM WAV。已有此文件后，以下命令生成候选、接入学习页并验收音乐库。

```powershell
& 'work/reference-library-20261105/audio-env/Scripts/python.exe' -X utf8 "$r/scripts/audio/separate-local.py" V22
& $node "$r/scripts/audio/finalize-library.mjs" V22
& $python -X utf8 'work/reference-v22/index-reference.py'
& $node "$r/scripts/build-study.mjs"
& $node "$r/scripts/audio/validate-library.mjs"
```

先开[总览图](../evidence/V22/overview.jpg)找章节，再用[JPG 映射表](../data/frame-analysis/V22-jpg-map.csv)找具体帧。例：F118 是 1.966667 秒，在 60 fps 播放流里是第 119 张图。画面和声音用各自的时间戳，不能用整秒播放器读数代替切点。
