# V23 ·《绿皮书》原片与混剪归属

本机混剪样本 H.264 / 1440×1080 / 30 fps / 747 帧，首帧 F000，末帧 F746，画面结束边界 24.900 秒。看片的镜头来自《绿皮书》（Green Book，2018）。画面反复出现 Mahershala Ali 饰演的 Don Shirley 与 Viggo Mortensen 饰演的 Tony Lip，F162 的书、F228–247 的公路雨夜、F650 的酒吧、F719 起 Linda Cardellini 饰演的 Dolores 拥抱 Don 都与人物和情节相符。电影家庭影音资料标明 2.00:1，V23 为 4:3。 [环球电影官方资料](https://www.universalpictures.com/movies/green-book) · [环球家庭影音发行规格](https://www.universalpicturesathome.com/press-release/green-book-press-release)

## 混剪新增可复练的形态

| 混剪帧 | 看见的做法 | 复练要点 |
| --- | --- | --- |
| F029→030，F039→040→047 | 钢琴键右窗先高亮，短暂转为手部画面。下一次白层沿人物头和上身轮廓，颜色恢复时琴键继续在背景，直到 F047 改由舞台乐手作底。 | 矩形窗、人物遮罩和底图有独立时间。给人物形状单做浅色提示，过门时保持人物位置和动作。 |
| F080→086→091→096→104→106→110→111→121→122 | 灰色场景中仅人物及其周围矩形恢复颜色。左竖窗、右竖窗、上横窗、下横窗、中央竖窗逐个换图。各次亮层只在新窗口出现，已有区域仍保留。 | 先锁来镜窗形，再定局部亮层 1–2 帧及新画面进入的时刻。左/右竖窗和上/下横窗可以互换层级。 |
| F169→174→179→180→184 | 书中小矩形开成公路，车流铺满。随后两位餐桌人物与桌子先出轮廓，再着色，背后的道路直到 F184 才换室内。 | 用道具的矩形轮廓放大开窗。抠像至少包含人物、桌面和下缘，保留中间能看到道路的空隙。F179 与 F180 的轮廓及颜色分开验收。 |
| F216–226，F385–396 | 白天山壁与夜灯用直切线并置。另一段日/夜 Cadillac 则用矩形叠窗，车尾作为视线锚点，后者仍保持为小窗就进下一镜。 | 同物件放在相近位置与尺度，先对齐车顶、左右灯或保险杠，再决定窗形。主画面可以只保留局部，不要求每个窗都放大到全屏。 |
| F248–250、F261–262、F397/401/405、F636/640/644 | 两到三块斜带或直带依次着图。下一块的高亮只占自己的区域，前一块保持正常画面。F645 后三竖带整合。 | 一个底图与几条剪切路径共用时钟。把局部闪层与内容独立，形状决定闪光边界。 |
| F480→481、F500→501、F506→507 | 可见画面细节的高亮区域只占目标窗口。相邻帧内，局部明暗方向显著反转。 | 可先从来镜得到负片式亮层，短时恢复正常颜色；对白画面保持可读。参数需要根据新素材亮度调。 |
| F695→703、F704→709、F714→719 | 三次短矩形接力带出笑容、弹琴与拥抱。尾部拥抱满屏持续至 F746。 | 前两段先把人物表情放进窗，再换整幅。最后一次接管后留表情，让结尾由演员动作收住。 |

局部闪层像素抽查在 720×540 抽样图上选择遮罩内部窗口，将闪层和正常画面的灰度求 Pearson 相关。F249→250、F397→398、F480→481、F500→501、F506→507、F640→641 的相关在 −0.872 至 −0.962 之间，支持局部负片式明暗翻转。F104 与 F121 的选区约全为近白（灰度 ≥245），F039→040 的相关为 +0.807 且近白比例较低，对应浅色人形层。抽查用于区分现象，原工程的具体曝光曲线、混合模式和软件仍未确认。 [像素抽查 CSV](V23-局部闪层像素抽查.csv)
