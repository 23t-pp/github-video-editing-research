# V23《绿皮书》混剪的音频与卡点

本地上传片的 AAC 原混音为 44.1 kHz、双声道，解码后每声道 1,098,663 个样本，时长 24.912993 秒。30 fps 的画面为 747 帧、24.900 秒，两个流从零起算。混音在 FFmpeg EBU R128 口径下为 −9.3 LUFS、+0.4 dBTP。

## 对白、音乐与尾声

- 本地 Whisper 自动与英语模式均在 5.34–12.14 秒识别出一段英语对白，主题是暴力无法赢得尊重，以及尊严终会胜出。分离候选和原混音同采样点相减后，英语模式仍识别出这段话，且对 `dignity` 的辨识更完整。具体词与起止时间有识别误差。分离候选的识别结果在不同语言模式间互相矛盾，曲名保持未识别。 [本地识别对照](asr-stem-comparison.json)
- UVR 模型生成的音乐主体候选保留了对白段的伴奏，区间 5.34–12.14 秒的混音与候选 RMS 分别是 −13.15 和 −18.07 dBFS。12.5–23.8 秒候选与混音的单声道波形零滞后相关为 0.99994，候选增益匹配后只剩 −48.96 dBFS RMS 的差值。由此可确认后段的主要声响和节奏都随分离候选保留。模型也可能留下其他声音。 [波形与频带对照](audio-audit-with-stem.json)
- 对白读完到白天车尾接管约留 0.36 秒，随后有约 12.497、12.851 和 13.225 秒三个明显谱峰。23.833 秒的拥抱小窗及 23.967 秒铺满附近没有明显新峰，拥抱段与音乐衰减重合。23.8–23.9 秒为 −11.0 dBFS RMS，24.4–24.5 秒已降至 −70.9 dBFS RMS。 [逐 100 ms 电平](mix-levels-100ms.csv)

## 节奏与逐帧对照

独立能量分析给整段约 74.1 BPM，前半段高频相关中有 0.809–0.813 秒间隔支持这个候选，也允许把它当作 148 BPM 的半速计数。相关系数仅约 0.14，且音乐主体候选在对白区间给出的主要周期约 0.511–0.520 秒，因此前半段只保留候选。12.14 秒后，原混音与音乐主体候选都有明显约 0.335–0.337 秒脉冲和约 0.670 秒的倍长周期，可数约 179 BPM 或 89.6 BPM，另有约 0.169 秒高频细分。数据支持分段说明。
