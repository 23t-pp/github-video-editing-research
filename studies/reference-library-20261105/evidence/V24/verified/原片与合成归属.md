# V24 原片对照

把《头号玩家》本机电影的每四帧缩为一张 96×54 灰度代理，共 50,340 张。先用不同取景范围找相似候选，再对候选附近解码连续彩色帧，按头盔反光、钥匙、车轮、机械细部和背景位置目视核对。最后复核 201,357 个原片包 PTS，25 个对照中的解码 PTS 和显示序号一致。原片为 24000/1001 fps，时间刻度为毫秒；参考混剪为 30 fps。匹配表示找到相近的同一画面，部分近静止镜头允许相邻原帧歧义。
