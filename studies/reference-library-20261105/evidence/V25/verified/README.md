## 独立复核

- 逐帧按 30 fps 检查，重点回看变化发生前后。同一层先出现纯白轮廓，下一帧又在同一区域露出另一条来镜，这组前后关系能区分局部遮罩和全屏白闪。F0017 和 F0317 接近全屏白，F0495 则保留明显的头发和肩膀边缘。
- 以 F0072 起的六次白窗和 F0455 起的三次白窗为例，连续触发点都相隔四源帧，间隔约 133.33 毫秒。它们是可从画面复核的节奏单位。对白、音乐节拍与音效瞬态分别以音轨分析为准。
- F0541、F0547、F0549 显示的是红色对峙在相近构图下的不同亮度与轮廓。计镜头时应先核对背景和人物位置，画面差分峰值可用于筛候选。
- 叠层、遮挡、形状和出现顺序来自成片。火花、能量束、色光、碎裂和运动模糊的具体制作来源，以及原作者软件、插件和模板名称，都需要原片或工程才能进一步核实。
