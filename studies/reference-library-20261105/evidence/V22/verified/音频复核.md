# V22 音频复核

抖音公开播放版有一条 HE-AACv2、44.1 kHz、2 声道音轨。解码得到每声道 836,575 个样本，约 18.969955 秒。画面流长 18.950 秒，音频尾端比画面长约 20 毫秒。左右声道相关系数 0.999983，分析中保留原解码时间零点。曲名仍待确认，分享重定向中的音乐 ID 为 `7558686869215939363`。

中文人声和音乐共存。多语 Whisper 对原混音自动判为普通话（98.5% 模型概率），对“原混音减音乐候选”得到的算术残差也自动判为普通话（99.3%）。结合画面字卡，约 1.6–9.9 秒先用声音解释记忆、供奉照片和过桥的规则，约 9.9–18.3 秒转到亲人忘记自己、女儿和回家的情绪。字幕与人声跨过镜头边界，镜头可以独立跟节奏变化。识别文本有错字，声线来源和个别字词仍待试听核对。各取 13 个画面已对位点附近的特征片英、中文音轨做波形匹配，均未找到稳定的同时间位置对应，所以不能凭画面判断是哪句原声。

用 46.44 毫秒 Hann 分析窗、4.99 毫秒步长观察六个频段的正向能量变化。重复节奏间隔约 0.261 秒，以八分音符计约 115 BPM。约 0.52 秒和 1.04 秒也有相关峰，所以 BPM 取法依赖拍型判断。对照模型提取的音乐主体，25–250 Hz 的起音在该节奏格上的相位集中度从原混音 0.492 增至 0.818，算术残差为 0.194。音乐候选保持节奏骨架，普通话自动识别未形成可靠句子，仍可能带有残余成分。

剪辑练习时，先确定切换中负责卡点的是预入场、最亮一帧、信息第一次可读，还是完全铺满。F118 的城景卡可辨、F204 的剪影抬亮、F925 的上横条开始、F1078 的橙字初显都贴近测得的音头。F429 已开始换放射背景，明显早于附近的中频音头。F887 画面开始大幅切换，晚于附近强低频音头。不要把频谱峰统一归类为鼓点。音乐、人声和音效都能产生这些峰。

`audit.py` 用 FFmpeg 解码到标准输出，再由 NumPy 计算频带能量。`onset-candidates.csv` 保存混音的候选音头，`cue-alignment.csv` 记录对照帧和偏差，正值表示画面晚于音头。`transcribe.py` 在本机执行多语 Whisper；候选文本仅用于判断结构。`compare-feature-sound.py` 记录已知同画面位置的英、中文原片音轨相关性。实际对齐量化受一个 60 fps 帧格和约 5 毫秒分析步长限制。
