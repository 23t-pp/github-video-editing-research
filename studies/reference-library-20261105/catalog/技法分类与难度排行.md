# 技法分类与难度排行

20条参考片可归入18类可复用手法。先按素材的锚点、动作与边缘条件选做法，再按题材筛选。**实际制作证据仅覆盖V05六格结构迁移、HF渲染、OCC分层和portable导入；其余是等效配方或待原片/预处理，不能借V05结果宣称全部实测。**

本目录综合三组review；V01–V10以native_review边界纠正为准，V16–V20保留该分支未精读全部原生页的限制。V11–V15本分支实际查看过57页原生atlas，但不宣称以全分辨率观看所有帧。时间为原生PTS对应；低于60fps不升帧，每页60格只是排版。

## T01 硬切与动作/形状匹配

**2/5：**操作简单，难在找到同方向、相近位置与动作相位的两段素材；背景明显变化也可成立。

**适用素材：**同向旋转道具、挥手、射网、拳脚命中；景别接近、主体锚点清晰、有完整起手/接触/后摇的片段。

**不适用/易错：**相反旋转方向又无中间动作；主体尺度/视线跳太大，靠裁切会丢关键内容。

**当前状态：**等效配方：未实际复刻渲染。

- **V06 81.708–81.792秒：旋转枪跨片硬切。** F1961/81.708秒：灰白CG环境中的旋转枪；F1962/81.750秒：下一原帧直接变为暖色真人室内。[native-033.jpg](../evidence/V06/native-033.jpg)
- **V20 12.933–13.000秒：手机切出是硬切，不是屏幕放大门户。** F388/12.933秒：手机外框仍完整；F389/12.967秒：直接换完整院落/车上人物场景。[native-007.jpg](../evidence/V20/native-007.jpg)
- **V14 0.433–1.233秒：相似姿态AB短组交替。** F13/0.433秒：蓝色回头脸换受伤侧脸；F18/0.600秒：短暂回蓝色版本。[native-001.jpg](../evidence/V14/native-001.jpg)

**等效步骤**（建议参数与原工程恢复值分开）：

1. 先标两镜的动作峰值、运动方向、锚点坐标与主体大小。
2. 先用普通硬切接，不先加效果；以注视点连续为验收标准。
3. 必要时少量裁切/平移/缩放；有变速需求先试短段恒速。
4. 按源帧和PTS作±1–3帧试切，再独立核对声音。

**OpenChatCut：**原生时间线切镜、trim、恒速、基础位置缩放；保留各源片可编辑。

**HyperFrames：**只在需要文字/图形层时补充；匹配硬切本身不需要HF shader。

**来源与限制：**原参数、软件、插件与全部源片时间码未知；下述步骤为等效方案。；成片内CG、光效或画面处理可能源片已存在；无未剪原片对照，不能逐项认定为混剪新增。

## T02 短叠化与构图对齐

**2/5：**短透明度交叉变化容易做；主体未对齐会产生双影，叠化不能代替素材筛选。

**适用素材：**握手、背头、正脸等位置接近的双镜；暗部/大色块相近、短重叠不影响阅读的片段。

**不适用/易错：**两个主体大小和角度差异悬殊；关键运动需要清楚冲击，不宜长时间双曝光。

**当前状态：**等效配方：未实际复刻渲染。

- **V06 55.875–56.083秒：握手短叠化。** F1342/55.917秒：握手双曝光开始；F1345/56.042秒：第二组背景已清楚。[native-023.jpg](../evidence/V06/native-023.jpg)
- **V11 6.867–7.167秒：短重叠换场。** F206/6.867秒：室内和外部火场双曝光阶段；F215/7.167秒：室外火场已经明确。[native-004.jpg](../evidence/V11/native-004.jpg)

**等效步骤**（建议参数与原工程恢复值分开）：

1. 对齐手、眼或肩等一个主要锚点，统一主体占屏比例。
2. A与B保留短重叠，透明度反向变化。
3. 检查重叠中间帧是否出现不合理双手、双眼或亮度突升。
4. 硬切与叠化AB比较，选最能表达关系的一个。

**OpenChatCut：**多轨重叠、opacity关键帧或已有转场；草稿完成后保留两源。

**HyperFrames：**如需不规则过桥可做图层合成；普通叠化无需复杂模板。

## T03 六格/几何拼图与同源窗口

**3/5：**每格共享同一画面时钟、裁切互补、显现时序不同；多视频实例和原生工程的同步是主要工程点。

**适用素材：**一段可分成3×2仍有可读信息的B镜头；A背景留出中心区域，B有足够分辨率与源帧余量；可裁切的风景、人物或车辆宽景。

**不适用/易错：**六格各播一份完整画面却想拼成同一人物；源片分辨率低、主体刚好压在格缝且不能调整。

**当前状态：**已实测：仅V05结构迁移小样中的六格子例。

**等效步骤**（建议参数与原工程恢复值分开）：

1. 一份B预合成/源视频复制为6窗口；按全画布坐标互补裁切。

3. 需要白卡/轮廓桥时另设短白覆盖层；不要把它误认成纯opacity。
4. 窗口全部完成后接B全幅，确认源时间连续；只混一次B原声或使用Master。

**OpenChatCut：**已实测7视频轨（6格+底轨）、独立crop/scale/opacity/y关键帧，独立Master；另有HF整合序列。

**HyperFrames：**已实测4.5秒/24fps六格HTML制作、108帧原生渲染与最终MP4；HF内部图层仍回HF编辑。

**来源与限制：**只实测FastX素材的结构迁移版：A0–48帧、六格30–48、B48–108，整体scale=.72；未复刻原动画动作、音乐、亮白细节、原缓动或模糊，不是100%复刻。；成片内CG、光效或画面处理可能源片已存在；无未剪原片对照，不能逐项认定为混剪新增。

## T04 照片墙与独立卡片错时入场

**3/5：**几何动画较直接，复杂度来自多卡比例、留白、层级和视线引导；不等于动态人物抠像。

## 初学者学习顺序

1. **T18 / T01：**用V20手机F388→F389例子练硬切；做一条不带花式转场的动作接镜与尾停留。 验收：注视点和动作方向可读；不把手机框凭空扩张。
2. **T02 / T14：**做两个握手/侧脸短叠化，另做V14式同姿态AB与去色。 验收：没有明显双手/双眼错位；不称AI变形。
3. **T04 / T05：**以V13三张风景卡为起点，再做半脸/上下分屏。 验收：窗口清楚、卡内素材比例正确、留出阅读时间。
4. **T03：**打开V05实际小样，换A/B素材，检查六格源时钟、crop、音轨与两工具工程。 验收：六格拼成一幅连续B而非六份完整B；只播一份Master；portable能导入。
5. **T10 / T11 / T12 / T15：**拆一个短标题、RGB字效、REC框或简单CRT原型，不一次叠满。 验收：说清是文字还是全视频处理；过门后恢复清晰；未实测项仍标配方。
6. **T06 / T13：**先做稳定圆窗或正面手机屏，再处理透视和轮辐/眼罩前景。 验收：窗口放大时源时间连续，边框与前景遮挡正确。
7. **T07 / T08 / T09 / T17：**V12/人物短段只做一处动态alpha：白形→自然人→体内填水。 验收：边缘、指缝、遮挡与同源时钟逐段检查；不能只用静态mask冒充。
8. **T16：**最后再决定原创光线3D/解体是否值得，先找对应原片/plate做简版。 验收：资源/渲染链路明确；没有资源就承认近似，不能声称恢复电影CG。

## 四个必须保留的判断
