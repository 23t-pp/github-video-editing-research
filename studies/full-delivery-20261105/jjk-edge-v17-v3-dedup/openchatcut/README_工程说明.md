# 挚友 · EDGE · 画面去重V3 · OpenChatCut 工程说明

本工程是《挚友 · EDGE》画面去重V3，为1920×1080、24fps、1440帧，即60秒。沿用edge原曲147–207秒，替换21处重复主镜头，保留主要字效、撕边和遮挡技法，并调整重复人物前景。V1、V2项目与交付保留。工程包使用官方导出器制作，再通过官方导入器真实重开；106项媒体全部恢复，missing 0，逐媒体SHA256一致。

- 工程包：挚友 · EDGE · 画面去重V3.ccproj（320,608,648字节）。
- [原工程](http://127.0.0.1:5199/#/editor/9f2a9af5-654d-4384-adfd-c7dc88b222a9) · [官方导入验证副本](http://127.0.0.1:5199/#/editor/0ab946b8-8403-4b4e-9907-db57a4aad3e6)。本机链接需要5199服务；跨机器使用ccproj导入。

## 打开与修改

1. 在OpenChatCut项目首页选择“导入项目”，打开本目录ccproj。
2. 默认序列“01 HF完整效果”包含20段效果预合成视频和独立master.wav，可移动、裁切、替换每段视频。
3. 切换至“02 原生逐镜”可编辑67个独立镜头及8个原生文字片段的顺序、入点和时长。
4. 两条序列各有一条独立master音乐；视频全部静音，不叠加原片声音。
5. 人物抠像、SVG文字、撕边、发光电弧、粒子及复杂空间合成在旁边HyperFrames工程保留源码；修改后重新渲染对应HF片段并在OpenChatCut替换。原生逐镜用于换镜头，HF序列用于完整视觉预览。实际执行效果与剩余差异以主交付参考对照说明为准。

原生序列的8个文字片段采用最大36号字、画布下方安全区，作为学习标签。复杂SVG文字与HF字效保留在HyperFrames工程内，OpenChatCut原生序列没有展开这些复杂字效。
