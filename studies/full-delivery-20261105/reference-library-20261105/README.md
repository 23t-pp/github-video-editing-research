## 三分钟打开学习页

1. 解压学习库，进入里面有`index.html`和`scripts`的目录。在资源管理器地址栏输入`powershell`，回车。
2. 执行下列命令。`node`是运行JavaScript脚本的程序；`serve-library.mjs`启动仅供本机访问的学习页。

```powershell
node .\scripts\serve-library.mjs
```

3. 浏览器打开 **http://127.0.0.1:5212**。保持PowerShell窗口运行；学习结束后按`Ctrl+C`停止。若5212被占用，可先执行`$env:PORT='5213'`再启动，浏览器改为对应端口。

本机实测时，PATH上的Node遇到写入限制，改用Codex自带Node才正常。若你的电脑也是这个情况，等价命令为：

```powershell
& 'C:\Users\PC\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' .\scripts\serve-library.mjs
```

`&`是PowerShell的调用符，让带空格或引号的完整程序路径可以执行。没有关闭防护、修改系统权限。

**图谱与文字不需要原视频。** 要在页内播放你的原视频，复制`local-media-paths.example.json`为`local-media-paths.json`，填入自己电脑的真实路径。配置只在本机使用，Git会忽略它，服务也不提供该文件的下载。

```json
{
  "V01": "C:/Users/你的用户名/Downloads/参考视频.mp4",
  "V05": "D:/素材/六格参考.mp4"
}
```

学习页“原生帧证据”页签会给出每页帧号和时间戳。原尺寸单帧读取需要FFmpeg：若不在当前默认位置，启动前设置`$env:FFMPEG_PATH='你的ffmpeg.exe完整路径'`。使用解码帧序号定位，不用浏览器近似拖动充当准确逐帧定位。

## 这次的结果怎样理解

### 1. 全量解码，不等于全部人工精读

机器确实解码、计算并排版了全部17,290张原帧；每帧有真实PTS、变化量、亮度、直方图差异等数据。人工看过所有视频的总览/逐秒图谱，并明确记录了111页原生帧图谱的重点复核。V11–V15的57页原生帧图谱全部查看；其他视频为关键区域复核。

**没有声称人工逐张精读17,290张全分辨率画面。** 小图能确认构图、硬切、卡片显隐、白闪等，不能证明发丝边缘、亚像素遮罩和原始滤镜参数。学习分段是方便理解的章节，可能含多个切镜，不是恢复出的作者EDL。V06还有嵌套的重点复盘段，所以205个学习段也不是205个互不重叠的镜头。

### 2. 视觉现象、等效实现、原作者工程是三件事

- “F55开始出现白色卡片”是证据中可看见的事实。
- “用六个裁切窗口、白色覆盖和独立显现重做”是实现配方。
- “原作者用了某个插件、某个模板”需要原工程或可核验来源，仅凭成片不能确认。

所以报告不承诺100%还原作者工程，也不把原电影的爆炸、全息影像、摄影机运动都算成剪辑师额外做的特效。相同素材提高复刻可能性；源片段、音乐、字体、遮罩和调色参数也会影响结果。

### 3. 音乐库有两层

`audio/mixed`保存原视频的混合音轨，AAC编码流复制，无音频重编码；每条有编码内容哈希与完整性记录。`audio/music-candidates`或索引指定目录保存本地模型分离的音乐主体候选；路径以[统一音乐索引](data/audio/music-index.json)为准。

候选可能保留引擎、冲击、环境声，也可能损失歌声、合成器或瞬态。它不是“保证干净的原版伴奏”。本轮没有通过人耳确认曲名或节拍，曲名字段保持未知，不能把视频文件名当歌曲识别结果。完整过程见[音频处理说明](data/audio/processing-notes.md)。

卡点分析使用声音起音、模型拍点和视觉事件最近邻。接近某个声音起音不证明作者在卡音乐：那个声音也可能是对白或拳击。页内表格帮助你定位复听，不能代替审美判断。

### 4. 去重保留来源

20条视频的SHA-256均不同，没有删掉任何参考。音频按AAC编码内容和固定格式解码PCM分别核验；“不同片段来自同一首歌”不能靠文件哈希判定，暂不强行合并。未来同一文件改名会被哈希认出；不同转码需要另外做人审和内容指纹。

## 最值得你先练的三件事

1. **先学动作匹配。** V14的相似姿态、V06的握手/举枪、V20的视线与动作切换，先做两镜头即可。位置、方向、动作阶段比转场数量重要。
2. **再学几何窗口。** V13的矩形、菱形、横条，以及V05六格更容易做成可换素材模板。V05已经完成两工具实际小样，但原参考的亮白入场、放大模糊、动画人物与音乐并未等同复刻。
3. **最后学动态alpha。** V12看似只是风景，实际有建筑、佛头、人物分层；V15还有人物内填视频和短排字。动态遮罩要求源素材与跟踪质量，不是套一个转场就能完成。
