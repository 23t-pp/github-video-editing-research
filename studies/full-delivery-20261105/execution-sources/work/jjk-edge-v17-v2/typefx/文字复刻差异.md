# V2 精细文字：证据、实现与差异

## 实际查看的参考

V02是1920×1080、30fps、743原生帧。本次真实查看`outputs/jjk-edge-v17/evidence/v02-type/V02-type-keyframes.jpg`的21帧联系图，原尺寸查看F109和F165，并查看参考库`evidence/V02/native-002.jpg`与`native-003.jpg`原生图谱（F60–179）。没有把图谱浏览称作全片原尺寸逐帧验收。未试听V02，不将未确认的英文认作歌词。

观察依据：F0极窄高白字，F2横向解压；F109字形呈圆环，F113展开为窄高直立字；F120上排大字、F124下排错拍进入；F137–164双排左右相反运动；F165收成环；F174–207黄底长句、红黑斜纹与粗侧面。角色在字前的遮挡由总合成人物alpha负责。

## 已执行的改进

- `slam`完整可编辑SVG英文源：约2输出帧极窄高→展开，随后回弹；黑描边、红色9层挤出、细高光。字号与字宽分别控制，避免中文方块承担整个画面。
- `twin`两排可编辑SVG字，左右相反横入，下排默认晚3输出帧。紫填充、白侧面和细高光，稳定宽约80–90%画幅。
- `orbit`与`cylinder`使用Barlow Condensed ExtraBold原字体离线轮廓。每个轮廓点按连续曲面公式映射，不使用整块rotationY冒充非线性。`orbit`圆环→5帧展开→柱面窄高字，末4帧可回收成环。
- 原先尝试32列切片、32×6局部网格；原尺寸渲染发现细接缝，最终默认改为连续SVG路径，消除边界。旧`geometry='slices'`仅留作研究，不用于本片交付。
- `ribbon`连续路径红黑斜纹、巨大窄高字和反向横漂。`board=True`提供漫画黄红或紫蓝底、网点、手工不规则墨线边缘。
- 所有模式在事件40%和73%附近有有限衰减的比例脉冲与微小横抖，不靠无限循环保持活动。可用`pulse=False`关闭。
- 大英文负责冲击，小中文只写角色语义；本片原创文字不是歌曲歌词。示例`THE STRONGEST / 最强·五条悟`、`GOJO GETO / ONLY FRIEND / 唯一的挚友`、`NO LIMIT / 无下限`、`PURPLE / 虚式·茈`。

## 真实渲染验收

`V02精细文字_3秒短样.mp4`来自真实HyperFrames CLI的72帧PNG序列，24fps、1920×1080。它是独立无声文字工艺短样，没有伪造为最终人物合成。已真实查看关键帧联系图，以及F15、F24、F44、F63等原尺寸输出，确认连续路径无切缝、窄高字和细斜纹清晰。

另将同一事件中途的全局F19–26单独作为新工程渲染8帧，与完整短样对应帧逐像素比较：8/8完全相同。跨72帧chunk采用相同全局elapsed公式，任意中途chunk不会重播入场。结果和SHA-256见`短样验收.json`。

CLI lint零错误，4条内嵌SVG结构建议（父合成采用内联模块）。validate零错误、零运行警告；本次关闭WCAG自动对比度采样，因为主字最终位于动态角色之后，最终对比应看总合成。

## 接入与编辑

复制`typefx.py`和`barlow-glyphs.json`到同一目录。Python仅用标准库；浏览器只用父工程GSAP，无联网、额外JS、时钟、随机和异步timeline。

接口仍为`type_layers(events, fps, first, last) -> (html, css, gsap_lines)`。区间都是全局输出整数帧，左含右不含。父定义`tl`和timeline注册。父字体需定义`Barlow Condensed`（或事件`font='JJK Latin'`）和`JJK Heavy`，并将人物alpha置于`z`之上。

```python
dict(id='friend',start=669,end=720,mode='twin',
     text=['GOJO GETO','ONLY FRIEND'],subtitle='唯一的挚友',
     font_size=450,width=1600,board=True,z=40,track=81)
dict(id='limit',start=840,end=876,mode='orbit',text='NO LIMIT',
     subtitle='无下限',font_size=560,width=1600,board=True,z=40,track=82)
```

可配`x/y/width/font_size/scale_x/scale_y/color/stroke/depth/stroke_width/board/board_color/edge_color/subtitle/subtitle_y/pulse/line_delay/ring_exit/ring_radius_x/ring_radius_y/ring_phase/z/track`。`orbit/cylinder/ribbon`主字使用本地预采样ASCII大写轮廓（A–Z、数字和常见标点），中文放`subtitle`；不增加运行时字体库。改主字应在Python事件中改`text`并重新生成，连续路径随之重建；SVG defs仍保留文字源供查阅，直接改那条隐藏text不会自动重建已变形path。`slam/twin`可直接编辑SVG text。

## 尚存差异

V02原准确字体和原插件未知；本次是按可见字比例与运动重建，不声称恢复原工程。连续映射能形成真实圆环/柱面，但环形各字的具体曲率和原片F109鱼眼形态不同。挤出采用9层屏幕偏移，不是物理光照3D字。短样不含动态人物，前后遮挡及关键词可读性由总工程最终验收。没有复制作者水印、未确认歌词或原片系列标志。
