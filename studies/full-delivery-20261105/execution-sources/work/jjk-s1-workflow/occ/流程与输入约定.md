# 第一季 OpenChatCut 独立工程流程

当前仅完成隔离脚本准备，**尚未创建工程、导入媒体或导出包**。这些脚本由编排层通知设计B通过、最终媒体锁定后才执行。

## 隔离和保护

- 当前输出：`outputs/jjk-s1-workflow/openchatcut`。
- 当前状态：`work/jjk-s1-workflow/occ/state.json`，首次执行前不存在。
- 不复制旧任务的state、args、日志、项目ID或导入副本ID。
- 使用现有5199服务及原隔离开发profile；通过官方CLI新建独立工程。
- V1/V2的四个源与导入工程ID在client中禁止写入；当前任务只允许写新建S1 UUID，不能复用任何既有项目ID。创建前保存既有Doc哈希；四个固定保护项目要求不变，其他授权分支可能合法并行变化，仅记录差异，不回滚、不覆盖，也不仅据差异归咎本任务。
- 所有媒体必须是新任务目录内准备好的片段；禁止直接引用旧V1/V2资产目录或把整集加入此工程包。

## 等待的输入

默认清单：`outputs/jjk-s1-workflow/hyperframes/edit.json`。

```json
{
  "title": "新片名",
  "width": 1920,
  "height": 1080,
  "fps": 24,
  "durationFrames": 1440,
  "audio": {"master": "../music/master.wav"},
  "assets": [{"id":"C001","asset":"assets/shots/C001.mp4"}],
  "shots": [{"id":"S01","asset":"assets/shots/C001.mp4","startFrame":0,"frames":48,"assetStartFrame":12}],
  "nativeTexts": [{"id":"label","text":"咒术","startFrame":12,"frames":24,"fontSize":36}]
}
```

- 示例只有一镜，实际`shots`须从F0连续到F1440，无空洞、重叠或源区间越界；镜头数量不写死。
- 路径相对清单所在目录。音乐可放`../music/master.wav`或HF本地assets；必须是48kHz双声道、60秒。
- 准备视频必须1920×1080、24fps、无音轨；原生序列逐镜引用这些高分准备素材，不能用640×360审片替代。
- `assets`可保留候选备用片；重复绝对路径只导入一次。每个媒体文件名与SHA应能唯一对应。
- `nativeTexts`可省略，若有则是最大36号、下方安全区的小学习标签，完整艺术文字仍在HF工程。
- 原生镜头的`reframe`是HF画布像素位置与倍率；写入OCC时用`x/width*100`、`y/height*100`、原倍率scale，并按官方接口的0.01%/0.001精度量化。写入后与最终重新导入副本均回读验收；不是仅在报告中声称同步。
- `hfChunks`可显式提供。省略时按已约定路径读`../occ-effects/HF-0000-0072.mp4`至`HF-1368-1440.mp4`共20段，每段72帧。

## 编排放行门

脚本未携带`authorization.json`，因此任何正式写入会先失败。收到编排层明确B审核和final媒体锁定通知后，本代理才建立授权文件，其中绑定当前清单SHA、`designBApproved=true`、`finalMediaLocked=true`、`approvedByOrchestrator=/root`和阶段白名单。清单改动后授权失效。

阶段白名单使用`native/hf/mutate/export/import/finalize`。`mutate`是官方CLI的具体工具写入保护；并不授予修改旧工程的权限。

## 执行顺序

1. `run.ps1 validate`：源/音乐/20段HF的本机ffprobe与结构校验，只读。
2. `run.ps1 native`：官方CLI创建独立工程，导入准备素材，放置原生镜头、小标签和一次master。
3. `run.ps1 hf`：添加20段效果序列，视频静音，独立master，默认打开HF序列；保持原生序列不变。
4. `run.ps1 export`：调用官方`buildProjectExport`，GET-only本地适配器，记录包媒体字节、SHA与missing。
5. `run.ps1 import`：调用官方`importProjectPackage`，创建新的验证副本，媒体上传和项目写入均走官方接口；旧工程受保护。
6. `run.ps1 finalize`：回读两套工程的连续1440帧、镜数、标签、master、媒体字节与结构。

UI播放与拖动验收由编排层另行操作。本脚本不把后端导入通过冒充实际听觉试听或界面播放。

索引写入只向官方服务提交本次新导入UUID的metadata，由官方服务在锁内合并当前索引；不提交旧profile快照覆盖其他分支的新变化。具体edit工具调用另记`write-target-audit.jsonl`，每个目标必须等于本S1新UUID。

本机命令示例：

```powershell
& 'D:/gpt/2026-11-04/ps-c-windows-system32-winget-install-2/work/jjk-s1-workflow/occ/run.ps1' validate
```

正式执行需要媒体到位与阶段门通过。首次准备阶段只做Node语法校验和禁止写入门校验，不访问用户工程状态。
