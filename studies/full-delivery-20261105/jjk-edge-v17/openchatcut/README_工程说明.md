# 挚友 · EDGE · V17主参考 / V02字效 · OpenChatCut 工程说明

本工程为1920×1080、24fps、1440帧，即60秒。主参考V17，字效参考V02。工程包使用官方导出器制作，再通过官方导入器真实重开；68项媒体全部恢复，missing 0，逐媒体SHA256一致。

- 工程包：挚友 · EDGE · V17主参考 _ V02字效.ccproj（200,824,109字节）。
- [原工程](http://127.0.0.1:5199/#/editor/db290905-d92d-40c3-bf6d-b978bc074d9e) · [官方导入验证副本](http://127.0.0.1:5199/#/editor/dc02577e-2c3e-435f-9515-51411e73ced4)。本机链接需要5199服务；跨机器使用ccproj导入。

## 打开与修改

1. 在OpenChatCut项目首页选择“导入项目”，打开本目录ccproj。
2. 默认序列“01 HF完整效果”包含20段效果预合成视频和独立master.wav，可移动、裁切、替换每段视频。
3. 切换至“02 原生逐镜”可编辑67个独立镜头及5个原生文字片段的顺序、入点和时长。
4. 两条序列各有一条独立master音乐；视频全部静音，不叠加原片声音。
5. V17运动、遮罩、透视及V02复杂字效在旁边HyperFrames工程保留源码；修改后重新渲染对应HF片段并在OpenChatCut替换。原生逐镜用于换镜头，HF序列用于完整视觉预览。

原生序列的5个文字片段采用36号字、画布下方安全区，作为学习标签。复杂HF字效保留在HyperFrames工程内，OpenChatCut原生序列没有展开这些复杂字效。
