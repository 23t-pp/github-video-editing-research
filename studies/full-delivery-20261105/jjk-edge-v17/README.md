# 挚友 · EDGE

用你提供的 `edge.mp3` 与《咒术回战》第二季素材制作的一分钟混剪。V17是人物关系与转场的主参考，V02是文字效果副参考。

**先看 [成片：挚友_EDGE_一分钟.mp4](挚友_EDGE_一分钟.mp4)。** 成片为1920×1080、24fps、1440帧，精确60秒。音乐取自你这份文件的 **2:27–3:27**，保持原速，固定降3dB，首尾做极短淡入与淡出。

## 看懂这支片

前段用受伤五条与双人日常建立关系；16秒附近跟随音乐低谷进入黑场与蓝折线；约28秒用“最强 / 觉醒”和动态人物开启高能动作链；末段把战斗映入实际镜片后收口。

|成片位置|实际制作的效果|主要参考|
|---|---|---|
|11秒|暖色双人记忆窗进入冷色礼堂|V17冷暖空间互相侵入|
|12.17秒、18.79秒|锯齿纸边纵向人像，内部视频继续运动|V17撕边人物|
|26秒|分别调整两张脸的尺度与位置，再沿中线拼合|V17双半脸|
|27.875–29.875秒|双排紫字、白轮廓、洋红挤出、浅蓝漫画板；真实动态五条在字前|V02排字与人物前后层次|
|32.25秒|大掌先进入旧红球画面，随后完整新镜从相同源时钟接上|V17伸掌先入、背景后换|
|56.46秒附近|前一战斗镜放进原片实际镜片内，保留镜片边缘|V17镜片记忆|
|58–60秒|向右侧圆镜片收口，跟随音乐尾部结束|镜片与音乐收尾的改编|

这是一支按新音乐与一分钟结构重新编排的混剪。原参考的文字内容、细小形变、镜头时位和遮挡边缘未逐像素重建。撕边使用手绘轮廓；双半脸是手工对位；镜片使用人工圆心与半径锚点。源动画自带的术式、玻璃、光束与碎石仍属于原片效果。
