# OpenChatCut 已启动：本机使用说明

打开：http://127.0.0.1:5199/

已验证：依赖安装、资源同步、中文首页、示例工程预览与时间线、停止后重新启动。

## 以后启动

```powershell
cd "$env:USERPROFILE\Desktop\OpenChatCut-main"
.\Start-OpenChatCut.ps1
```

cd 用来进入文件夹；第二行运行已经放好的启动脚本。保持这个终端打开。若已经启动，脚本会提示直接打开网页，不会重复启动。

## 停止

在启动终端按 Ctrl+C，或者另开 PowerShell：

```powershell
cd "$env:USERPROFILE\Desktop\OpenChatCut-main"
.\Stop-OpenChatCut.ps1
```

关闭浏览器不会停止服务。停止服务不会删除工程。没有设置开机自启。
