# V07库内原音乐：来源与30秒导出

本次直接使用音乐库内V07的音乐主体候选，不另作曲、不循环、不拉伸，不沿用旧作128 BPM。曲名**未知**，没有根据视频标题猜歌名。

来源为`outputs/reference-library-20261105/audio/music-candidates/V07__music-candidate.m4a`，对应用户参考视频`国漫无缝转场帅是一种感觉_不良人_光阴之外_仙逆_国漫_混剪.mp4`（V07）。该库文件是此前真实本地UVR处理得到的Instrumental候选，可能保留人声/SFX或损伤音乐，不能称为保证纯净的原版伴奏。

库内M4A已原样复制到`assets/audio/V07-library-original.m4a`，SHA256：`ab3f9d2cba177aa62d7d3bc3fd63d06ae17607ac5b9ee4f37e3655a709163654`，逐字节一致。

## 实际处理

原生解码1,323,008帧、44.1kHz双声道，30.000181406秒；只去除末尾8个极低电平采样帧（0.181406ms），保留1,323,000帧，再正常重采样到48kHz。固定线性降6.4dB，没有动态响度滤镜、音符生成或节奏变换。`loudnorm`只用于测量，未作用到成品。

成品`assets/audio/bgm.wav`为48kHz立体声PCM24，**1,440,000采样帧、30.000秒**。实测综合响度 **-16.00 LUFS**、真峰值 **-6.40 dBTP**、LRA **2.60 LU**。完整解码、采样数、有限值和无采样削波检查通过。SHA256：`5d54fa8488c14a298653c98303bfef4eb959976f0b609f4f71479c494bf1c532`。

预览用`assets/audio/master.wav`与bgm字节完全一致，尚未叠加汽车动作原声；后续加入源声必须另混并重新测总声，不能同时播放bgm和master。

25fps输出750帧；最后显示帧编号749，覆盖29.960–30.000秒，30.000为结束边界。原参考视频751帧的末画面帧不要求保留，因为当前剪辑长度由库内音乐决定。原有约29.424秒后的低电平收尾被保留，不能称为数学全零。

## 重建与验收范围

在工程根（有assets与audio-report的目录）运行：

```powershell
node .\audio-report\export-library-audio.mjs
```

脚本优先读取工作区的库文件；独立工程中缺少旧库时读取已经校验的`assets/audio/V07-library-original.m4a`。也可用`--source`指定同SHA的库文件。需要Node与FFmpeg；后者可用`FFMPEG_PATH`指定。遇Node写入限制时改用已有可写Node运行时。所有二进制由FFmpeg stdout返回给Node保存，不更改系统设置。

完整参数、实际响度、SHA、采样数和检查结果见`export-report.json`；起音数据见`priority-onsets.json/csv`。制作代理未实际监听，没有宣称听感、曲名、人声/SFX清除率或最终汽车声混音已验收。
