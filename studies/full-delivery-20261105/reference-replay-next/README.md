# 越界 · V07 动作接力复刻

这次以随机抽中的 **V07《国漫无缝转场帅是一种感觉》**为参考，把它的前景接力、遮挡换景和窗内穿越结构，迁移到你提供的《速度与激情》素材。

**音乐来自已有音乐库；片长跟随音乐。** 这首库内音轨约30秒，因此成片是30秒，不再套用一分钟。后续混剪也按这个规则执行。

这是一版**结构与技法迁移的复刻**。真人手势、光线和车身运动与原动画不同；轮胎不能重演原扇面翻开的三维形变；侧窗使用四角近似门户，未重建原参考的弯曲手指边缘。原电影自带的爆炸、飞车和直升机不是本次新制作的CG。具体差异见学习总结。

## 音乐从哪里来

来源是原音乐库的 `V07__music-candidate.m4a`。工程中的 [V07-library-original.m4a](hyperframes/assets/audio/V07-library-original.m4a) 是它的逐字节副本，SHA已核对；[bgm.wav](hyperframes/assets/audio/bgm.wav) 是用于成片的音轨，`master.wav`与它相同，没有叠加旧作曲或另一首音乐。

原音轨实际解码30.000181406秒。只去掉尾部8个极低电平采样帧（0.181406毫秒），正常重采样至48kHz并固定降低6.4dB，得到30.000秒。没有音乐变速、循环或重写旋律。详细记录在 [音频报告](hyperframes/audio-report/README.md)。

这份音轨是此前分离得到的“音乐主体候选”，并非已确认曲名的原版纯伴奏；可能有分离残留。本轮做了采样、波形、响度和同步检查，制作代理没有实际听觉试听，不把这些检查说成听感验收。

## 打开本地对照播放器

在此文件夹打开PowerShell，执行：

```powershell
node .\player-server.mjs
```

浏览器打开 `http://127.0.0.1:5216`。左侧是成片，右侧是你本机已有的V07参考。点击“同步播放”同时走；右侧默认静音，避免两份声音叠加。“上一帧 / 下一帧”每次移动0.04秒。

若电脑重启后找不到 `node`，可使用本机实际运行时：

```powershell
& 'C:/Users/PC/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' .\player-server.mjs
```

参考视频没有额外复制进工程。播放器从相邻参考库的 `local-media-paths.json` 读取V07位置；换电脑后可以在同文件夹新建 `reference-source.local.json`，填入 `{"path":"你的参考视频绝对路径"}`。直接双击HTML仍可看成片，右侧参考需本地服务。
