# 弯心 / APEX

一条用《速度与激情》系列十部片源剪成的60秒短片。配乐为本片编写。1920×1080，24fps，共1440帧。

1. **先看成片。** 直接播放 [弯心_APEX_60秒.mp4](弯心_APEX_60秒.mp4)。
2. **再拆一个剪点。** 打开 [学习播放器](学习播放器.html)，点“追逐”，再点一次“上一帧”。第719帧是三位驾驶员，第720帧是一辆黑车冲出烟尘。时间、镜号和原片入点会随画面更新。
3. **想用鼠标改。** 在 OpenChatCut 导入 [弯心可编辑工程](openchatcut/弯心%20APEX%20·%20速度与激情一分钟混剪.ccproj)。01序列保留与成片相同的三个效果插片。02序列可以单独改文字、移动每个分屏窗口，两条序列都保留42个独立镜头和两条声轨。
4. **想改动效或音乐。** 解压 [HyperFrames可编辑工程](HyperFrames可编辑工程.zip)。在 `hyperframes` 文件夹运行 `Preview.cmd` 开启预览。旁边的 `music` 文件夹含MIDI、鼓、贝斯、合成器和氛围分轨。

按步骤练习、换素材和重新导出，请读 [中文剪辑学习手册](剪辑学习手册.md)。每一个正式镜头的源片编号、入点、成片位置和时长都可以在 [42镜头表](hyperframes/镜头表.csv) 里查到。

OpenChatCut工程包重新导入时恢复了48份媒体。取出01序列的真实镜头位置，配合HyperFrames的135个效果帧重新编码，得到与交付成片逐字节相同的MP4。[重建核验](evidence/双工程重建对照.json)
