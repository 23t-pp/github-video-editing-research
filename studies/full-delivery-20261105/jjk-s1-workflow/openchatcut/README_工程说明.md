# 咒力接力 · CURSED FLOW · OpenChatCut 工程说明

本工程是《咒术回战》第一季独立混剪，为1920×1080、24fps、1440帧，即60秒。音乐使用已有曲库V20候选，经乐段复用与交叉过渡成为一分钟master。复杂视觉的实际实现与未验范围由主交付及四轮审核记录说明。既有V1/V2工程与交付保留。工程包使用官方导出器制作，再通过官方导入器真实重开；85项媒体全部恢复，missing 0，逐媒体SHA256一致。

- 工程包：咒力接力 · CURSED FLOW.ccproj（205,861,867字节）。
- [原工程](http://127.0.0.1:5199/#/editor/cd443d87-8dbd-4a57-a216-5a50374c3893) · [官方导入验证副本](http://127.0.0.1:5199/#/editor/be8d1fea-8e60-4e84-9e6d-43c0b5051640)。本机链接需要5199服务；跨机器使用ccproj导入。

## 打开与修改

1. 在OpenChatCut项目首页选择“导入项目”，打开本目录ccproj。
2. 默认序列“01 HF完整效果”包含20段效果预合成视频和独立master.wav，可移动、裁切、替换每段视频。
3. 切换至“02 原生逐镜”可编辑59个独立镜头及4个原生文字片段的顺序、入点和时长。
4. 两条序列各有一条独立master音乐；视频全部静音，不叠加原片声音。所有准备片段按1×重放，源→prepared变速/采样已烘入片段；不再套用清单中原源名义playbackRate，避免二次变速。
5. 人物抠像、SVG文字、撕边、发光电弧、粒子及复杂空间合成在旁边HyperFrames工程保留源码；修改后重新渲染对应HF片段并在OpenChatCut替换。原生逐镜用于换镜头，HF序列用于完整视觉预览。实际执行效果与剩余差异以主交付参考对照说明为准。

原生序列的4个文字片段采用最大36号字、画布下方安全区，作为学习标签。复杂SVG文字与HF字效保留在HyperFrames工程内，OpenChatCut原生序列没有展开这些复杂字效。
