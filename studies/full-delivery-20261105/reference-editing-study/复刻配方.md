# 从参考片变成能动手做的配方

下面是**等效实现建议**，不是反解出来的作者参数。时长、位移、羽化与缓动均是试验起点，必须用实际源素材修正。本次没有渲染这些复刻效果。

先懂四个词：底层先画，上层盖住底层；alpha是每个像素的透明程度；mask是决定哪里显示的形状；关键帧是“这个时刻这个参数是多少”。预合成就是把多层暂时当成一个整体继续处理。

## R01 · 六格视频拼图｜入门2/5

对应V05约1.7–2.3秒。

图层从下到上：A原镜 → B的六个裁切窗口 → 可选亮度冲击。六格并不是六个互不相关的视频：它们必须取B的**同一源时刻**，这样拼起来才是一张连续画面。

1. 把一个矩形分成3列2行，每格裁B不同区域，保持相同播放时间。
2. 先出现一格，再依次补齐；30fps工程可从每格错开2帧开始试。
3. 小卡片形成后，接B全幅或下一动作。若需要放大，把六格作为一个整体放大，别让各格各自漂移。
4. 字幕若压在卡片上，另放一层，避免烘焙进素材。

适配：HyperFrames的DOM/SVG裁切与时间线；本地grid-card-assemble可参考结构，是否直接可用见组件适配文档。OCC可以摆多轨，但程序化生成重复窗口更容易保持一致。

验收：格与格没有不同步；边界没多一像素黑线；接全幅时人物不跳位置。先不抠人物也能练。

## R02 · 圆形揭示/圆形穿越｜2–3/5

对应V01胸口圆窗；V10为透视与前景遮挡升级版。

图层：A完整旧镜 → B新镜（圆形mask）→ 可选前景边缘。

1. 选圆心，例如胸口或车标中心。先用固定圆心，后续再跟随。
2. 让B的mask半径由小变大，最终覆盖画布四角；`circle(50%)`不一定覆盖宽屏四角，必须检查最后一帧。
3. B的视频缩放和mask大小分别控制。窗口变大时，B中的人不要意外不断长大到错位。
4. 在mask覆盖全屏后继续B完整画面，不能突然回到另一个裁切位置。

建议初值：持续6–12源帧，边缘羽化从1–3像素试，最后几帧减速。不是越软越好；大羽化可能漏出旧背景。

V10特殊要求：斜视角的圆形车标呈椭圆/透视形状；轮毂需要把轮辐留在最上方。一个不带轮辐的圆窗只能复现简化观感。

## R03 · 前景先入，背景后换｜4–5/5

对应V03手/袖口，V07持剑手臂，V08人物换入。

```text
上层 V3：B的手/人物alpha ────────────
中层 V2：                  B完整镜头 ─────────
底层 V1：A完整旧镜头 ────────────────
                    ↑先看到B前景  ↑再换B背景
```

最关键的是：V3在每个时间点都和V2引用B的同一个源帧。不要把B前景提前播放，却让B全幅从第0帧重新开始。

1. 找B中正在进入镜头的手/袖口/人物。
2. 提取动态alpha，先叠到A上。提前0.2–0.5秒可作试验范围。
3. 选前景遮挡大、速度快或局部变亮的时刻，切换B完整背景。
4. 合流后去掉多余alpha副本，避免同一边缘叠两次变暗/发亮。
5. 逐帧查指缝、袖口内空洞、头发、边缘运动模糊。静态PNG平移无法替代手腕旋转和衣袖真实动作。

OCC安排三轨与基础关键帧；复杂mask在外部准备/在HF组合。HF的人物抠像路径尚未在这些镜头上测试，尤其不能假定它适合3D动漫手指。

验收：新旧背景确实独立切换；前景无跳帧/双影；手指中间没有整块旧背景残留。

## R04 · 眼形/指缝门户｜4–5/5

对应V04眼罩、V07双指三角、V10轮孔。

图层：A完整画面 → 被内窗mask裁切的B → A手指/眼罩边/轮辐前景。

1. 先给静止的一帧画mask：眼形用SVG路径；三角指缝先用多边形。
2. B放入窗口后，对齐B的视觉中心。窗口不是一定要在画面正中。
3. 若边界会动，逐时更新路径或跟踪顶点；若有透视变化，单纯x/y跟踪不够。
4. 前景手指或轮辐另放上层，保持“B在孔后面”的遮挡关系。
5. 窗口扩大到全屏时，B的全幅必须和窗内画面连续。

当前OCC源码中的简易跟踪主要是位置追随，不能据此承诺三角顶点、3D姿态或透视跟踪。HF可以表达路径，但路径数据仍需获得和修正。

验收：看得出“穿过孔”，不是把整张B透明贴上；边界每帧贴合；最后切全幅不抖。

## R05 · 动作匹配与声音落点｜2–3/5，选材可能很费时

对应V06的旋转枪、握手、胸部受击；也适合蜘蛛侠射蛛丝与摆荡。

先填四个锚点：屏幕位置(x,y)、主体大小、主要运动方向、动作阶段（蓄力/接触/后摇）。

1. A最后一帧与B第一帧先直接硬切。
2. 若运动中断，换入出点；若主体突然跑远，少量裁切/缩放修正。
3. 需要时给连接前后少量位置和旋转关键帧，而不是整镜强行扭成一致。
4. 匹配源素材速度时可先用短段恒速；连续速度曲线与光流应作为独立、尚未验证的处理步骤。
5. 对照声音，让接触/命中落在真正的重点附近。按±1–3帧试切，正常速度回看。

V06握手与旋转枪的区别：55.917秒附近可见短叠化，81.750秒是直接硬切。因此不要给同类动作统一套一种转场。握手例子可从24fps下3–5帧叠化试起。

验收：观众的视线不需要突然寻找主体；物体继续朝合理方向运动；音效不重复；原镜自带光效不被叠两遍。

## R06 · 漫画人物/白剪影/CRT尾声｜3–4/5

这是三个短模块，不能用同一个模板假装全部完成。

**漫画人物**：底色与网点 → 大字 → 人物alpha → 局部装饰。把字放人物后面需要真实透明前景。描边可由alpha膨胀形成，白边试2–6像素起步，按输出尺寸调整。不要给整幅视频加描边。

**白剪影换人**：A底图 → 白色B形状 → 正常B人物 → B全幅。白形状要引用B的alpha而不是画一个大白矩形。1–2帧短白可以试，真实时长待源帧与声音确认。

**CRT关机**：最后画面预合成 → 弧边/圆角窗口与轻扫描线 → `scaleY`迅速变小 → `scaleX`再收小 → 黑。可以从0.2秒压成横线、再0.2–0.3秒收成亮点试起。亮线发光只持续很短，别让整个尾声过曝。

## 每一项交付时都保留什么

- 可读的配方：用哪条源片、哪个时间段、哪层在前。
- 参数：开始/结束帧、锚点、mask、缩放、旋转与声音事件。
- 可编辑合成源文件：HF HTML/脚本/素材引用。
- 给OCC使用的渲染片段：确认尺寸、帧率、音频是否重复、alpha是否正确。
- 对比图：关键前、中、后3帧，加正常速度回放结果。
